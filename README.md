This package is a JAX implementation of the iCATS sparse-attention method (arXiv 2610.11302): interaction-aware query and key clustering, the SNR-guided top-p schedule, and the tail-merge procedure from Appendix E.1. It is the algorithm, not a video generator. Install with `pip install -e .`. Run with `icats-demo`. Test with `JAX_PLATFORMS=cpu python -m pytest -q`. It does not run Hunyuan or Wan inference and does not report PSNR or VBench numbers. Tests and the demo use a synthetic noise schedule a_t = 1 - t/T, b_t = t/T for t = 1..T-1 instead of Wan's schedule. Cluster-centroid softmax uses temperature 1/sqrt(d), which the paper does not state. If a metric is singular or a cluster is empty, the metric is symmetrized and jittered by 1e-6 times the identity.
